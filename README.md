# Expense Tracker

A simple beginner-friendly Python mini project to record and manage daily expenses.

## Features

- Add an expense
- View all expenses
- Calculate total expenses
- Store data in a CSV file

## Technologies Used

- Python
- CSV file handling

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python expense_tracker.py
```

## Example

```text
===== EXPENSE TRACKER =====
1. Add Expense
2. View Expenses
3. Total Expenses
4. Exit
```
